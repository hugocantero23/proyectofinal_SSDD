# Dados Distribuidos

### Trabajos para la asignatura de Sistemas Distribuidos

Juego en red multijugador en el que los jugadores lanzan dos dados por turnos, ganando quien primero llegue o supere los 20 puntos.

### **Reglas del juego**
- Puede haber una única partida activa, con entre 2 y 4 jugadores.
- Un jugador crea la partida indicando el nombre y el número total de jugadores, incluido él mismo.
- Los demás se incorporan usando el nombre de la partida.
- Al ocupar todas las plazas, la partida comienza y juega primero quien la creó.
- En su turno, cada jugador lanza dos dados de seis caras. El servidor suma el resultado a su puntuación.
- Gana el primer jugador que alcanza o supera 20 puntos.
